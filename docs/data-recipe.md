# 数据配方

## 预训练语料

### 当前配方

| 项目 | 值 |
|------|-----|
| 主语料 | t2t_mini 中文问答语料 (1.2GB, 127万行) |
| 辅语料 | 公众号文章 210篇 (38万字符) |
| 清洗工具 | `data_pipeline/preprocess_pretrain.py` v2 |
| 主语料提取量 | 500万字符 |
| 合并总量 | 530万字符 |
| Token 数 | 245万 tokens (SentencePiece 16K) |

### 清洗规则 (preprocess_pretrain.py v2)

1. 从 JSONL 提取 `text` 字段
2. 去除开头的提示词（给我/帮我/请/写一个/根据等）
3. 按问句标记拆分多轮问答（好的/明白了/那/请问/能否等）
4. 每段只保留回答部分，去掉问题部分
5. 质量过滤：长度 50-1500 字符，中文占比 > 15%
6. 截取 500 万字符

### 问题与改进方向

- t2t_mini 是问答碎片，不是连贯文章，单条平均仅 264 字符
- 缺少长文本（小说、新闻、维基百科）
- 长文本占比应 > 70%

### 公众号抽取策略 (gen_sft.py)

| 策略 | 说明 | 示例 |
|------|------|------|
| title_intro | 标题→问题，开头段落→回答 | "什么是大模型？" |
| sections | ##标题→问题，段落→回答 | "连接越容易，感情越便宜？" |
| what_is | "X是Y"句型→"什么是X？" | "什么是注意力机制？" |
| why | "因为/原因是"→"为什么" | "为什么要残差连接？" |
| how_to | "应该/需要"→"怎么做" | "银行应该怎么做？" |
| blockquotes | 引用→金句问答 | "最重要的一句话是什么？" |
| multi_turn | 多段落→2-3轮对话 | 标题→追问→追问 |

| conclusion | 文章末段→结论 | "结论是什么？" |
| list_items | 列表项拆分 | 单独问答 |
| data_points | 数字/百分比→数据问答 | "数据说明了什么？" |
| paragraph_summary | 段落要点提取 | "要点是什么？" |
| definition | "X是指Y"→定义问答 | "什么是RAG？" |

### 清洗规则 (clean_sft.py)

**问题过滤：**
- 长度 5-80 字符
- 必须以 `？` 结尾
- 拒绝碎片开头（而且/但是/因为/所以等 25 个）
- 中文+字母占比 > 40%
- 拒绝纯数字、纯符号

**回答过滤：**
- 长度 30-600 字符
- 中文占比 > 15%
- 拒绝表格/列表（换行 > 5 次）
- 必须以标点结尾
- 拒绝占位符（XXX/TODO/N/A 等）
- 数字占比 < 30%

**标点规范化：**
- 统一全角标点（？！：；（）等）
- 去重复标点（。。→。）
- 去多余空格
- 去 HTML/markdown 残留

**相关性检查：**
- 问题关键词在回答中是否出现
- 定义类问题（"什么"开头）放宽检查

**去重：**
- 按首个问题去重
- 重复问题保留第一条

## 分词器

### 当前配方

| 项目 | 值 |
|------|-----|
| 类型 | SentencePiece BPE |
| 词表大小 | 16,000 |
| 训练语料 | mixed-corpus.txt (530万字符) |

### 历史对比

| 版本 | 类型 | 词表 | 训练语料 | "银行"tokens | "大模型"tokens |
|------|------|------|----------|-------------|---------------|
| v1 | char | 127 | vocab.txt | 2 | 3 |
| v2 | tiktoken gpt2 | 50,257 | OpenAI预训练 | 5 | 7 |
| v3 | tiktoken cl100k | 100,277 | OpenAI预训练 | 3 | 3 |
| v4 | SentencePiece | 8,000 | 公众号39万 | 1 | 1 |
| v5 | SentencePiece | 16,000 | 混合530万 | 2 | 2 |

### 统一接口

```python
from model.tokenizer import Tokenizer

# 三种后端，同一接口
tk = Tokenizer("char", vocab_path="data/vocab.txt")
tk = Tokenizer("cl100k_base")
tk = Tokenizer("sentencepiece", model_path="data/mixed-sp.model")

# 统一方法
ids = tk.encode("你好")
text = tk.decode(ids)
size = tk.vocab_size
```

### 改进方向

- 词表大小实验（16K vs 32K vs 64K）
- 在更大语料上训练分词器
- 评估不同词表大小对中文 token 效率的影响
